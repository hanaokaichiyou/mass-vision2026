アプリを開いたらすぐに作成を開始できます。
画面は主に5つに分かれています。
- **編集エリア** 画面中央にあるエリア。マスが表示され、編集・再生が行われる部分。
- **左エリア** 画面左側にあるエリア。拡大されたマスと案内表示、様々な値の入力欄が現れる領域があります。
- **右エリア** 画面右側にあるエリア。編集時に使うツールがまとめられています。右クリックで前の画面に戻ります。
- **上エリア** 画面上側にあるエリア。シーンとカウントが表示されるエリアで操作の必要はありません。
- **下エリア** 画面下側にあるエリア。マクロの入力欄が現れるエリア。
### 編集エリアのスクロール
編集エリアは中央に青色のマスがあり、その周りに入退場を表すための余白があります(余白はパンフレットには印刷されません。あくまで作成しやすくするためです)。スクロールするにはメニューバーの「画面固定」→「解除」をクリックします。固定するには「画面固定」→「固定」をクリックします。「画面固定」→「中心固定」をクリックすると、自動で中心までスクロールされ、固定されます。
### 編集エリアの拡大
編集エリア上でマウスのホイールクリックまたは「Ctrl+L」をすることで編集エリアでの拡大画面の表示をON/OFFできます。
### 人を配置
右側にある「配置」ボタンをクリックします。
配置には5種類あります。
- **点配置**　「・」のボタンを押します。1人だけを配置します。
- **矩形配置** 「□」のボタンを押します。指定した矩形領域の周上及び内部に縦横の人数を指定して配置します。(矩形は「くけい」と読み、長方形のことです。)
- **円配置** 「〇」のボタンを押します。指定した円の円周上に指定した人数を配置します。
- **直線配置** 「／」のボタンを押します。指定した線分上に指定した人数を配置します。
- **間隔指定配置** 「⇔」のボタンを押します。指定した一点を始点とし、縦横の人同士の間隔と人数を指定して配置します。

ボタンを押すと左エリアに案内が出ます。
**点・値の指定について**、点の指定は編集エリア上でクリック、人数等の指定は左エリアに現れる入力欄、選択ボックス等で行います。案内に「正確な点選択」とあるものはマウスのボタンを押してから離すまでの間、赤い点の動きが鈍くなるので左エリア上部の拡大画面と合わせることで正確に点を選択できます。

その他配置に含まれる機能は以下の通りです。
- **削除** 「🗑」のボタンを押します。指定した範囲の人を削除します。
- **整列** 「整」のボタンを押します。指定した範囲の人を指定した整列単位(１マスなら、マスの交点上)で一番近いところに移動します。
- **対称** 対称には7種類あります。
  - **「x軸対称」、「y軸対称」、「45°-225°対称」、「135°-315°対称」** それぞれ、x軸、y軸、y=x、y=-xの直線に対称になるように指定した範囲の人を複製します。
  - **「原点対称」** 原点に対称になるように指定した範囲の人を複製します。
  - **「R90度回転」「L90度回転」** それぞれ右・左に90°回転させた位置に指定した範囲の人を複製します。
- **切り取り** 「✄」のボタンを押します。指定した範囲の人を別の指定した場所に移動します(元居た場所からは削除されます)。
- **コピー** 「📋」のボタンを押します。指定した範囲の人を別の指定した場所に新たな人として複製します(元居た場所にも残ります)。
- **リサイクル** 「♲」のボタンを押します。ひとつ前のシーンの最終位置をそのままコピーします。

**各メニューのショートカットについて**、上のメニューバーのメニューは添えられているショートカットキーを使用します。右エリアのショートカットは「1.配置」「・(1)」などとあるものは **「Alt+(その数字)」のショートカットでフォーカス** できます(Enterを押せばクリックしたことになります)。

### 初期方向の設定
初期方向の設定は「初期方向設定」と「特殊初期方向設定」の2種類あります。

#### 初期方向設定
右エリアの「初期方向設定」を押します。左エリアで、初期方向と適用範囲を指定します。基本的に最初のシーンにしか使いません。
#### 特殊初期方向設定
初期方向をある一点を向く方向に設定するツールです。
右エリアの「特殊初期方向設定」を押します。向く方向を指定する点を指定し、適用範囲を指定します。

### マクロの編集
マクロとは、人の動きを記述したプログラムのようなものです。マクロ式と呼ばれる言語で記述します。一つのマクロは一つの一連の動きに対応し、同じ動きをする人には同じマクロを適用します。一部だけ違う動きをする場合は変数を使うことで同じマクロでも微妙に違う動きを表現できます。
右エリアのマクロ編集を押します。
#### マクロの追加
「+　マクロを追加」を押します。下エリアに現れたマクロの入力欄にマクロを入力し、Enterキーで確定します。
#### マクロの編集
「編集」を押します。下エリアにマクロの入力欄が現れるのでマクロの追加と同様にします。
#### マクロの適用
編集エリアで人を選択すると、右エリアの選択ボックスで選択されているマクロが適用されます。
#### マクロ式
マクロはマクロ式で入力します。[c]はcカウントであることを表します。c,n,aなどの説明のついた文字には数字又は数式(後述)をあてはめます。<コメント>は「コメント」の部分をおきかえることで好きなコメント(日本語OK)をパンフに表示できます。<>は必要です。また、コメントは<>ごと省略できます。
- 歩行: **f{n}[c]** n...1マス当たりの歩数。nが3のとき{n}は省略可
- 後ろ歩き: **bw{n}[c]** 変数は同上。歩く向きが向いてる方向と逆になる。
- 方転(左): **tl{a}** a...方転する角度。角度はこれ以下も含め、全て45°単位で入力。
- 方転(右): **tr{a}** 同上。
- n方(左): **tlh{a}[c]** 同上。cカウントかけてゆっくり方転する。
- n方(右): **trh{a}[c]** 同上。
- 絶対方向方転: **t{a}** a...方転後に向く角度。
- n絶対方向方転: **th{a}[c]** 同上。cカウントかけてゆっくり方転する。
- ブレイク: **b<コメント>[c]** その場にcカウントとどまる。
- あしぶみ: **i<コメント>[c]** 同上。ブレイクと足踏みはアニメーション上では同じ。パンフでは同じ記号であしぶみと添えられる。
- 踊り: **dc<コメント>[c]** アニメーション上ではブレイクと同じ。パンフでは踊りの記号で表示される。
- 踊り+スライド: **dcs<コメント>{n}[c]** n...スライド番号。アニメーションではスライドと同じで、パンフは踊りと同じ。
- 流し: **wv<コメント>[c]** 始めに180度方転をして、cカウントブレイクする。パンフでは流しの記号で表示される。
- スライド: **s<コメント>{n}[c]** n...スライド番号
- 大回転(左): **rl{a}[c]** a...回転(公転)する角度。回転の中心はマスの中心。 
- 大回転(右): **rr{a}[c]** 同上
- ダイクロン: **dl{a}[c]** a...全体として回転する角度(公転角度)。左回りしかありません🙇。
- 座り: **sit[1]** カウント数は1で固定。変更しても1として解釈される。1/8マス下がる。
- 立ち: **std[1]** 同上。1/8マス進む。
#### 数式
変数、非負整数を用いた演算ができます。使用可能な演算は以下の通りです。

- **+** 足し算
- **-** 引き算
- **\*** 掛け算
- **/** 割り算(演算結果は小数。整数である必要があるところは自動で四捨五入される。)
- **%** 剰余算(割ったあまりのこと。100%3=1)
- **sin(x)** 正弦関数。xはラジアン。
- **cos(x)** 余弦関数。xはラジアン。 
- **tan(x)** 正接関数。xはラジアン。 
- **atan(x)** 逆正接関数。atan(1.73) ≒ π/3
- **sqrt(x)** 平方根。sqrt(4) = 2
- **abs(x)** 絶対値。abs(-2) = 2
- **floor(x)** 小数の切り捨て。floor(1.3) = 1, floor(-1.3) = -2
- **ceil(x)** 小数の切り上げ。ceil(1.3) = 2, ceil(-1.3) = -1
- **round(x)** 小数の四捨五入。round(1.3) = 1, round(1.5) = 2, round(-1.5) = -1, round(-1.6) = -2

使用できる変数は変数設定にあるg～rまでの小文字です。変数設定で各人に設定した値を数値として利用できます。マクロ式内で値を変更することはできません。

### スライドの編集
スライドとはマクロ式では表現できないような直線移動を実現するための機能です。人毎に目的地を設定し、そこへ向かって指定したカウントで直線移動させます。
右エリアのスライド編集を押します。
#### スライドの追加
「+　スライドを追加」を押します。
#### 目的地の編集
セレクトボックスから編集したいスライドを選びます。
「目的地を編集」を押します。人の配置画面に似た画面が表示されるので人の配置と同じようにして目的地を配置していきます。
#### リンク
右クリックしてスライド編集の画面に戻り、「リンク」をクリックします。人と目的地を交互にクリックすることで人と目的地を繋ぐことができます。ここでクリックした人のマクロ式に「s{スライド番号}[カウント]」を入力することでその人が繋がれた目的地に強制的に直線移動します。(リンクした時の黄色い線は誰がどの目的地に行くかを指定しているだけで、必ずしも線の向きに進むわけではありません。fマクロ等で移動した後でも目的地に向かって進みます。)
### 人の色分け
右エリアの色分けをクリックします。
始め全ての人は白の色が割り当てられています。セレクトボックスで色を選択して適用範囲を決めることで人に色をつけることができます。
### 人の番号の確認、振り直し
番号の確認、番号と色の振り直しをすることができます。番号は各シーンの人に配置時に割り振られます。リサイクルで配置したときは前シーンの番号が引き継がれますが、手動で配置したときは前シーンと独立に割り振られます。踏みがつながっている人に一貫した番号を振り、色を統一する作業が番号振り直しです。この時、基準シーンに合わせて番号・色がそろえられます。
右エリアの番号をクリックします。
#### 番号確認
番号確認を押して、編集エリアで人をクリックするとその人の番号が確認できます。(例: 「id: 19」)

#### 番号振り直し
「基準のシーン」を選択し、「番号振り直し」をクリックするとそのシーンを基準にして番号が振りなおされます。

### パンフ設定
パンフレットを印刷するときに人を塗りつぶすかどうかを各色ごとに設定します。
### 変数設定
指定した変数の値を指定した人に割り振ります。指定した変数はマクロ式の中で使えます。
変数は複数人同時に設定できます。範囲選択の始点に一番近い人に初期値が設定され、近い順に増分ずつ足されながら設定されます。セレクトボックスから設定したい変数名を選択し、「値」には初期値、「増分」には増分を設定します。マス上で範囲選択することで設定できます。
### パンフの出力
上にあるメニューバーの「ファイル」→「印刷」→出力したいパートを選択すると出力できます。プリンターの選択で「PDFとして保存」等を選択することでPDFとして保存できます。パート毎に若干パンフの表示が異なるので出力したいパートに合わせてください。
